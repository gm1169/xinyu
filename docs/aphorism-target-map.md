## 专家审核建议

1. 每条短句至少标注一个主要技术靶点，不超过三个。
2. 标注“禁用/慎用场景”，尤其是自伤自杀、精神病性症状、躁狂、物质依赖、家庭暴力等高风险情境。
3. 对现代哲思类短句做原创性和版权风险复核。
4. 审核记录应包含专家姓名、职称、单位、审核日期、修改意见和签名页。
