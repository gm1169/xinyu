# 格言心理治疗语料专家审核指南

## 审核目的

本指南用于对 `aphorism-corpus-stage1-annotated.csv` 中的格言语料进行精神医学、心理治疗和文化语义三方面审核。审核目标不是判断句子是否“优美”，而是判断其是否适合进入心理支持产品语境。

## 审核原则

1. 不把格言作为诊断、治疗或危机救援工具。
2. 不使用可能强化自责、羞耻、宿命感或过度忍耐的表达。
3. 不把文化经典简单等同于心理干预，需要明确心理靶点和适用边界。
4. 对危机、自伤、自杀、精神病性症状、躁狂状态等场景，格言只能作为支持性语言，必须提示人工或医疗资源。
5. 现代心理学家、文学家相关内容以思想转译呈现，不标注为直接引语，避免误引和版权风险。

## 专家评分维度

每条语料建议采用 1-5 分评分。

| 维度 | 评分含义 |
|---|---|
| 语言质量 | 是否凝练、清晰、有心理韵味、适合反复使用 |
| 心理靶点清晰度 | 是否能明确对应认知、情绪、行为、意义或关系靶点 |
| 临床安全性 | 是否避免自责强化、危机误导、创伤触发和不当暗示 |
| 适用场景匹配度 | 是否与标注的情绪、人群、练习任务相匹配 |
| 文化适配性 | 是否符合中文心理支持语境，避免生硬翻译或说教 |
| 产品可用性 | 是否适合 App、报告页、AI 对话和格言干预卡片展示 |

## 审核结论

建议使用四级结论：

| 结论 | 说明 |
|---|---|
| 通过 | 可进入产品语料库 |
| 修改后通过 | 需要调整解释、禁忌或练习任务 |
| 仅研究使用 | 可用于内部研究或专家讨论，不建议公开展示 |
| 剔除 | 不适合心理支持产品语境 |

## 一票否决项

出现以下情况建议直接剔除或仅内部使用：

1. 暗示用户应独自承受严重痛苦。
2. 对抑郁、自伤、自杀风险者可能形成诱导或合理化。
3. 将失败、疾病、痛苦归因于道德缺陷。
4. 强化“必须坚强”“不能求助”“忍耐就是美德”。
5. 现代文本版权不清且需要公开展示。
6. 来源无法核查，又被包装成名人原话。

## 推荐专家组成

建议至少 3 名专家：

1. 精神科医师 1 名：重点审核临床安全性和危机场景。
2. 心理治疗师 1 名：重点审核心理靶点和技术匹配。
3. 中文/传统文化或医学人文专家 1 名：重点审核文化语义和表达质量。

## 形成材料

申报或伦理材料中可形成以下附件：

1. 格言心理治疗语料库第一阶段标注表。
2. 专家审核评分表。
3. 专家修改意见汇总。
4. 剔除语料及原因记录。
5. 最终入库语料版本号与更新记录。
